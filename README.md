# AI 多仪器自动化测试：环境教程、实测复盘与理论架构

本仓库把一次多仪器自动化测试过程中的环境搭建、通信排查和经验提纯为两份教程，同时提供实测复盘、理论上限分析、社交平台发布文案以及脱敏后的来源与问题记录。

当前状态：**教程、Bug 台账、来源清单和三份公开报告已经完成。仓库不包含被测芯片型号、仪器地址、设备序列号、个人路径或登录凭据。**

四份 Markdown 是用户确认的网页版对话内容整理稿，可作为网页版来源使用。由于它们是整理后的总结文件，而不是包含逐条消息时间戳、原始图片和附件映射的完整会话导出，本记录将其证据等级标为“网页版对话二级总结”。

## 适用范围

本记录只覆盖以下通信链路：

1. RIGOL MSO5354 示波器：以太网 / TCP-IP VISA。
2. Keithley 2400 SMU：RS-232，经 CH340 USB 转串口适配器连接 Windows。
3. RIGOL DP831 直流电源：后面板 USB DEVICE，经 USBTMC 和 NI-VISA 连接 Windows。
4. Python、PyVISA、PyVISA-py、pyserial、PyMeasure、pymso5000 及 Codex STDIO MCP。

不覆盖 PCB、EasyEDA、探针接线、DUT 电气连接、具体测试限值或自动测试步骤。

## 安全与权限边界

本次整理没有连接或控制任何仪器，没有运行测试，也没有修改原工程、原日志或用户提供的总结文件。教程把验收分为“系统识别 → VISA 资源 → 身份查询 → 只读状态 → 状态写入/输出动作”五级；任何输出开关、量程、源值或其他状态写入，都必须另行取得明确授权。

公开仓库只提供环境和方法，不提供可直接照抄的真实设备地址、序列号或输出参数。使用者必须读取自己仪器的实际状态，并独立承担接线、电气安全、量程、校准和测试结论责任。

## 版本说明

文中的软件版本分为两种：

- “本机验证版本”是 2026-09-03 盘点到的本地版本，可用于复现这次环境。
- “官网下载版本”会随时间变化，部署时应从官方页面核对系统兼容性，不应长期照抄某个最新版本号。

网络地址、COM 号和 VISA 资源名均可能变化。历史值只用于说明格式，实际部署必须重新发现。
